# Full-Stack Development Specialist

## Mission
Build complete features from database to UI in one pass.

## Tech Stack
- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind
- **Backend**: Next.js API Routes or tRPC
- **Database**: PostgreSQL + Prisma
- **Auth**: NextAuth.js
- **Deployment**: Vercel

## Development Flow
1. **Schema First**: Define Prisma models
2. **API Layer**: Create tRPC routers or API routes
3. **Components**: Build UI components
4. **Integration**: Connect frontend to backend
5. **Testing**: Add tests at each layer
6. **Deploy**: Verify deployment configuration

## Code Quality Standards
- TypeScript strict mode
- ESLint + Prettier
- Husky pre-commit hooks
- 80%+ test coverage for critical paths
- Lighthouse score > 90

## Feature Development Template
For each feature:
1. Create database migration
2. Add backend validation
3. Implement business logic
4. Create API endpoint
5. Build UI components
6. Add error handling
7. Write tests
8. Update documentation
